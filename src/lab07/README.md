# ЛР-7 — Консольное приложение

## Цель работы

- Объединить код из ЛР-1 — ЛР-6 в одно рабочее приложение.
- Реализовать интерактивный CLI-интерфейс с меню и вводом пользователя.
- Добавить сохранение и загрузку данных через JSON-файл.
- Закрепить разделение программы на слои: CLI, бизнес-логика и хранение данных.

---

## Что реализовано

В ЛР-7 добавлены:

- консольное меню;
- добавление товаров;
- просмотр всех товаров;
- поиск товара по названию;
- фильтрация товаров;
- сортировка товаров;
- удаление товара с подтверждением;
- собственные исключения;
- сохранение и загрузка данных из JSON;
- аннотации типов;
- docstring для публичных методов.

Приложение работает с товарами из прошлых ЛР:

- `Product`;
- `DigitalProduct`;
- `Service`;
- `Accessory`.

Обычный `Product` используется для базовых товаров без дополнительных полей.

`DigitalProduct`, `Service` и `Accessory` используются для специализированных товаров.

Основная логика находится в файле `app.py`.

```python
class ShopApp:
    def __init__(self, filepath: str | None = None) -> None:
        self._collection: TypedCollection[ProductItem] = TypedCollection(
            (Product, DigitalProduct, Service, Accessory)
        )
        self._added_at: dict[str, str] = {}
```
---

Файлы ЛР-7:

- `main.py` — точка входа;
- `cli.py` — меню, ввод и вывод;
- `app.py` — бизнес-логика приложения;
- `exceptions.py` — собственные исключения;
- `storage.py` — работа с JSON-файлом;
- `lab07_products.json` — файл с сохранёнными товарами.

---

## Разделение на слои

В приложении используется разделение ответственности:

```text
cli.py      -> ввод и вывод
app.py      -> бизнес-логика
storage.py  -> сохранение и загрузка
models      -> классы товаров из прошлых ЛР
```

`cli.py` не работает с коллекцией напрямую. Он вызывает методы `ShopApp`:

```python
self._app.add_product(...)
self._app.add_digital_product(...)
self._app.add_service(...)
self._app.add_accessory(...)
self._app.find_by_name(name)
self._app.filter_by_price(min_price, max_price)
self._app.sort_items(strategy)
```

А `ShopApp` уже работает с `TypedCollection` из ЛР-6.

---

## Основные возможности CLI

После запуска появляется меню:

```text
1. Добавить товар
2. Показать все товары
3. Найти товар по названию
4. Фильтрация
5. Сортировка
6. Удалить товар
0. Сохранить и выйти
```

Приложение работает в цикле: после выполнения действия меню появляется снова.

Если пользователь вводит не число или неверный пункт меню, программа не падает, а выводит сообщение об ошибке.
---

## Добавление товаров

Пользователь может добавить один из трёх типов объектов:

```text
1. Обычный товар
2. Цифровой товар
3. Услуга
4. Аксессуар
```

Для каждого типа вводятся общие поля:

- название;
- цена;
- остаток;
- категория;
- скидка.

Для обычного Product вводятся только общие поля.

Также вводятся специальные поля.

Для `DigitalProduct`:

- размер файла;
- тип лицензии.

Для `Service`:

- длительность;
- выезд мастера.

Для `Accessory`:

- совместимость;
- беспроводной режим.

## Поиск и фильтрация

Поиск выполняется по названию:

Фильтрация реализована двумя способами:

```python
def filter_available(self) -> list[ProductItem]:
    ...


def filter_by_price(self, min_price: float, max_price: float) -> list[ProductItem]:
    ...
```

## Сортировка

В меню доступна сортировка:

```text
1. По названию
2. По цене
3. По дате добавления
```

Пример сортировки по названию:

```python
return sorted(items, key=lambda item: normalize(item.name))
```

Сортировка использует идею стратегий из ЛР-5: пользователь выбирает вариант, а приложение применяет нужную функцию сортировки.

## Собственные исключения

В файле `exceptions.py` реализованы исключения:

```python
class ItemNotFoundError(Exception):
    """Объект не найден в коллекции."""


class DuplicateItemError(Exception):
    """Объект с таким названием уже существует."""


class StorageError(Exception):
    """Ошибка при сохранении или загрузке данных."""
```

Они используются для ошибок предметной области.

Например, если добавить товар с уже существующим названием, приложение выбросит `DuplicateItemError`.

## Сохранение и загрузка

Данные сохраняются в файл:

```text
data/lab07_products.json
```

При запуске приложение автоматически загружает данные.

При выходе через пункт `0` данные сохраняются обратно в JSON.

```python
def save(items: list[ProductItem], filepath: str, added_at: dict[str, str] | None = None) -> None:
    """Сохранить список товаров в JSON-файл."""
```

```python
def load(filepath: str) -> tuple[list[ProductItem], dict[str, str]]:
    """Загрузить товары из JSON-файла."""
```
