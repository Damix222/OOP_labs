## Стратегии сортировки

Стратегии находятся в файле `strategies.py`.

- `by_name(item)` — сортировка по названию;
- `by_price(item)` — сортировка по цене;
- `by_category_and_name(item)` — сортировка по категории и названию;
- `by_total_price(item)` — сортировка по итоговой стоимости.

Пример:

```python
def by_price(item):
    return item.price
```

Для строк используется `normalize()`, чтобы корректно сравнивать названия и категории.

## `map`, `filter`, `sorted`

В работе используются встроенные функции высшего порядка:

```python
sorted(self, key=key_func)
filter(predicate, self)
map(func, self)
```

Они принимают другие функции как аргументы.

---

## Lambda

`lambda` используется для коротких одноразовых функций.

```python
catalog.sort_by(lambda item: normalize(item.name))
```

Это аналогично:

```python
catalog.sort_by(by_name)
```

---

## Фабрики функций и замыкания

Фабрика функций создаёт и возвращает другую функцию.

```python
def make_price_filter(max_price):
    def filter_fn(item):
        return item.price <= max_price

    return filter_fn
```

`filter_fn()` запоминает значение `max_price`. Это называется замыканием.

---

## Callable-объекты

Callable-объект — это объект, который можно вызвать как функцию. Для этого используется метод `__call__()`.

```python
class DiscountStrategy:
    def __call__(self, item):
        return item.final_price() * 0.9
```

Пример:

```python
catalog.apply(DiscountStrategy())
```

---

## Паттерн «Стратегия»

Паттерн «Стратегия» позволяет менять поведение программы без изменения кода коллекции.

```python
catalog.sort_by(by_price)
catalog.sort_by(by_total_price)
catalog.sort_by(by_category_and_name)
```

Метод `sort_by()` один и тот же, но результат меняется из-за разных стратегий.
